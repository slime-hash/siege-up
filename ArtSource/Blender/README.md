# Blender исходники

В этой папке хранятся исходные `.blend`-файлы моделей проекта.

Файлы находятся за пределами `Assets`, поэтому Unity не импортирует их как игровые ресурсы. В Unity попадают только экспортированные модели, текстуры и другие готовые ассеты.

Для каждого важного исходника желательно сохранять понятное имя, например:

```text
Castle_v01.blend
House_v01.blend
```

Крупные Blender-файлы хранятся через Git LFS.
