# Референсы

В этой папке хранятся изображения и другие визуальные материалы, которые используются для разработки игры:

- референсы зданий;
- примеры окружения;
- палитры и стилистические ориентиры;
- примеры интерфейса;
- изображения для сравнения результата.

Референсы находятся за пределами `Assets`, поэтому Unity не импортирует их в проект как игровые ресурсы.

По возможности сохраняй понятные имена файлов, например:

```text
village_ground_reference_01.png
castle_style_reference_01.jpg
ui_reference_01.png
```

При публикации игры нужно отдельно учитывать авторские права на найденные изображения. Эта папка предназначена для внутренней разработки и не является частью игрового контента.
